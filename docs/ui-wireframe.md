# TransitLog P0 界面线框（文字版）

> 视觉基调：延续 MemoRise 的**浅色纸感**（暖灰底 `#F3F4F6` + 白卡片 + 圆角），主色沿用同族绿色系；
> 深色主题另配一套 token（见 [requirements-review.md](./requirements-review.md#3-主题token体系)）。
> 交互原则：**卡片式列表** + **浮动加号(FAB)**，与 MemoRise 的 Material 风格一致。

---

## P0 页面清单

1. 登录/注册页
2. 主界面（行程列表）
3. 新增/编辑行程对话框
4. 统计页
5. 设置页（含主题切换、云同步管理）

---

```
│                                               │

│    │   [ 登录 ]   [注册]  (Tab 切换)          │

│    └──────────────────────────┘               │

```

- 登录/注册双 Tab，注册含"确认密码"。
- 底部一行**同步状态**：未登录时提示"数据仅保存在本机"。

## 2. 主界面（行程列表）—— 核心 P0

```
┌──────────────────────────────────────────────┐
│ ☰ TransitLog        ● 已同步 12:03    [浅色]  ◉ │ ← 顶栏: 侧栏/同步状态/主题切换/用户菜单
├──────────────────────────────────────────────┤
│  ▣ 8月3日 周六         今日 3 段 · 12.4 km      │ ← 按日期分组的表头
│  ┌──────────────────────────────────────────┐ │
│  │ 🚇 地铁    海淀黄庄 → 北京大学东门         │ │ ← 卡片: 图标+中文名 | 起→终
│  │  08:12–08:31 · 3.2 km · ¥4.00             │ │        时间区间 · 里程 · 费用
│  │  (备注: 早高峰人少)                        │ │        备注(有才显示)
│  └──────────────────────────────────────────┘ │
│  ┌──────────────────────────────────────────┐ │
│  │ 🚶 步行    ...                              │ │
│  └──────────────────────────────────────────┘ │
│  ▣ 8月2日 周五          昨日 5 段 · 18.7 km      │
│  ┌──────────────────────────────────────────┐ │
│  │ ...                                        │ │
│  └──────────────────────────────────────────┘ │
│                                               │
│                            ┌─────┐            │
│                            │  ＋  │  ← FAB 记行程 │
│                            └─────┘            │
└──────────────────────────────────────────────┘
```

- **卡片 = `TripRecord` 数据行**，左侧交通方式图标（来自 `transport_mode.icon`）。
- 顶栏右侧：同步状态点（绿=已同步 / 灰=离线 / 橙=同步中）、主题切换按钮、用户头像菜单（下拉: 设置/退出登录）。
- 搜索/筛选（P1）：顶部搜索框暂不做。

## 3. 新增 / 编辑行程对话框

```
┌───────────────────────────────┐
│ 记一段行程              [取消][保存] │
│  ┌──────────────────────────┐ │
│  │ 交通方式  (🚇地铁 🚌公交  🚶步行 │ │ ← 图标宫格，数据来自 transport_mode
│  │            🚲骑行 🚗驾车  ✈️飞机) │ │    空白态: 至少显示"其他"
│  └──────────────────────────┘ │
│  起点  [  海淀黄庄          ]  📍   │ ← 📍 可选: 拾取坐标(填 lat/lng)
│  终点  [  北京大学东门      ]  📍   │
│  开始  [ 2026-08-03 08:12 ]       │ ← QDateTimeEdit，默认"现在"
│  结束  [ 2026-08-03 08:31 ] (□进行中)│
│  里程  [ 3.2 ] km  ↺自动计算       │ ← 有坐标才可自动算，否则手填
│  费用  [ 4.00 ] 元                │
│  备注  [ 早高峰人少            ]   │
└───────────────────────────────┘
```

- 保存前**校验**：起点/终点至少填一个、时间合法（结束>开始，除非"进行中"）。
- 空数据容错：全部字段可留空只填时间也允许保存，但不能整行全空。
- "进行中"勾选 → `end_time` 存 NULL。

## 与 MemoRise 的样式对照

| 元素 | MemoRise 已有 | TransitLog 复用 |
|---|---|---|
| 背景/卡片 | `#f3f4f6` 底 + `#fff` 卡片 + 圆角 14px | 直接沿用 |
| 主色 | 绿 `#4A7C6F` / hover `#3D6B5E` | 沿用同族 |
| 按钮 | 主按钮实心绿 / 次按钮白底绿边 | 沿用 |
| 主题 | 只有浅色 + 背景图 | **新建深色 token 集**（见评审文档） |

> ⚠️ 注意：MemoRise 当前**没有深色主题**，也没有真正 token 抽象（颜色是硬编码十六进制）。所以"复用 token 体系"实际要做的是**先抽 ThemeManager**，详见需求评审文档第 3 点。
